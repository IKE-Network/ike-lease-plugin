# About IKE Working-Set Leases — IntelliJ Plugin

The IDE host of the lease core: opening a project acquires its lease and materializes its git state; being fenced by a takeover elsewhere saves open documents and closes the project; sibling pushes to remote remotes abort in the push dialog. Ships as a zip bundling this jar and ike-lease-core under lib/.
